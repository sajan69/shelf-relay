# ShelfRelay

A shared equipment-lending application for small clubs and studios: find available items, record handovers and keep kit returns visible when components are missing.

The intended workflow covers a catalogue, reservations, checkout, return checklists and overdue records for one organisation per installation. It excludes payments, automated borrower messages and safety-critical equipment decisions.

The repository currently has no runnable application or measured results. Demonstration records will be fictional; no member records have been imported.
